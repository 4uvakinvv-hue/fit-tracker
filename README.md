# Fit Tracker

Учебный и боевой проект мобильного приложения для тренировок и питания.

## Этап 1
- Android через Expo
- Главный экран
- Тренировки
- Питание
- Прогресс
- Профиль
- Без сервера и авторизации — пока данные живут только в памяти приложения

## Запуск
1. npm install
2. npx expo start --tunnel
3. Открыть ссылку проекта в Expo Go

Проект развивается через вайбкодинг: задача формулируется обычным языком, изменения в код вносит AI, пользователь проверяет результат на Android.
