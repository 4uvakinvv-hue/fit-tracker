# Стройка / Fit Tracker

PWA-приложение для тренировок, питания и отслеживания прогресса.

## Текущий этап

- Работает в браузере Android
- Можно установить на главный экран как приложение
- Первый запуск создаёт профиль пользователя
- Тренировки, питание и вес сохраняются локально на устройстве
- Код хранится в GitHub, изменения вносятся через вайбкодинг
- Следующий большой этап: Supabase — аккаунты и синхронизация между устройствами

## Разработка

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```

## Деплой

Рекомендуемый путь — подключить этот репозиторий к Vercel. После этого каждый push в `main` автоматически публикует новую версию.


## Публикация

Проект автоматически публикуется через GitHub Pages после каждого изменения в ветке `main`.
