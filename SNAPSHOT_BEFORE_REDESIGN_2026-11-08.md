## Что включено

Все **отслеживаемые Git** файлы проекта в момент фиксации: React/Vite/Capacitor исходники, JSX/CSS/SVG и сезонные стили, иллюстрации/медиа из `public/`, `src/`, `native/android/`, тесты, `.github/workflows/`, конфигурация сборки, SQL и Supabase Edge Functions из `supabase/`, `AGENTS.md`, **`docs/FORMA_PRODUCT_RULES.md`**, `docs/AI_COACH.md` и другие инструкции. Зависимости восстанавливаются через `package-lock.json` с `npm ci`.

**Важное ограничение:** сюда НЕ включены данные из действующей БД Supabase, личные правила в `private.coach_program_rules`, аккаунты, статистика, пользовательские фото, Supabase Auth, Secrets, значения переменных среды, внешние OAuth-настройки, отдельные APK из GitHub Releases и любые непрокоммиченные локальные изменения. Снимок исходников — не полный бэкап production-инфраструктуры.

## Как посмотреть или восстановить старую версию

**Безопасный способ для сравнения (не трогая современную `main`):**

```bash
git clone https://github.com/4uvakinvv-hue/fit-tracker.git forma-legacy
cd forma-legacy
git switch --detach c77f4d0825fd467cf96cb27a679ba006ecd891cc
npm ci
npm run build
npm test
```

Если нужно вернуться к старому коду как к новой рабочей базе, сначала создать отдельную ветку от этого коммита и проверить её. Не делать `git reset --hard`, `git push --force` или массовую перезапись `main` без отдельного решения владельца — это может уничтожить новый дизайн и данные.

**При работе с ZIP:** распаковать архив, установить Node.js 22, запустить `npm ci`, затем `npm run build`; для полноценного подключения Supabase потребуются безопасно полученные актуальные переменные среды и совместимая конфигурация БД.

## Контроль архива

- Базовый Git SHA является главным якорем: даже если архивная ветка будет дополнена служебными заметками, код на `c77f4d0825fd467cf96cb27a679ba006ecd891cc` останется тем же.
- Новые изменения дизайна и функций ведутся отдельно в `main`/рабочих ветках и не должны изменять этот архив.
- Перед релизом нового дизайна сравнивать код и утверждённые требования с этим снимком и с новыми утверждениями из `docs/FORMA_PRODUCT_RULES.md`.
