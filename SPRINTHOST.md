# Развёртывание Forma на Sprinthost

Текущая GitHub Pages версия остаётся рабочей. Этот пакет нужен для параллельного тестирования российской веб-версии.

1. Скачайте `forma-web-v1.7.0.zip` из релиза `web-v1.7.0`.
2. Создайте на Sprinthost отдельный домен или поддомен для Forma.
3. Распакуйте содержимое ZIP непосредственно в корневую папку сайта. В корне должен лежать `index.html`, а рядом папка `assets`.
4. Включите HTTPS для домена.
5. Откройте сайт и проверьте вход, календарь, историю, статистику, участников и добавление тренировки.
6. GitHub Pages и Android APK продолжают работать независимо. Менять ссылки в приложении нужно только после проверки Sprinthost.
